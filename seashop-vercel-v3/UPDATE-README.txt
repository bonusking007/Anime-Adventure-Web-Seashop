SEASHOP — UI UPDATE
อัปโหลดไฟล์ภายใน ZIP ทับในโฟลเดอร์ seashop-vercel-v3 เดิมบน GitHub
ไม่สร้างโฟลเดอร์ซ้อน และไม่ต้องเปลี่ยน Root Directory ถ้ายังใช้โฟลเดอร์เดิม
ไฟล์หน้าตาที่เปลี่ยน: public/index.html, public/assets/styles.css, public/assets/app.js

หน้าแรก 2D / รายชื่อผู้เล่นแบบการ์ด / จำนวนผู้ใช้ทั้งหมด / ตารางรางวัลรายคน
API และ Lua ใช้เหมือนเดิม ตั้ง BaseUrl และ TrackerKey ใน seashop-tracker.lua ก่อนรัน
TRACKER_VIEW_KEY ยังใช้สำหรับเปิด Dashboard
แสดงรางวัลรอบล่าสุด ไม่ใช่ inventory ทั้งหมดหรือประวัติหลายรอบ
บัญชีใน API เดิมหมดอายุหลังไม่ส่งข้อมูล 7 วัน

ตรวจ syntax และทดสอบการแสดง 6 บัญชี ปุ่มดูไอเทม ตาราง การค้นหา และค่าว่างด้วยข้อมูลจำลองแล้ว
ยังไม่ได้ทดสอบกับเกมจริง และสภาพแวดล้อมนี้เปิด Chromium เพื่อเช็กภาพไม่ได้
